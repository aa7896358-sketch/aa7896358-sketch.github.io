# 🏍 RiderCom

라이더 팀 인터컴 & 주행 기록 PWA

## 주요 기능

### 📡 팀 음성 통신
- WebRTC P2P 메시 네트워크 (최대 50명)
- 6자리 접속 코드로 간편 입장 (30분 유효)
- VOX 자동 송신 (음성 감지 시 자동 전송)
- 고급 노이즈 필터 (바람소리·엔진음 제거)
- 1인당 최대 4개 피어 연결 (부분 메시)

### 🏍 주행 정보
- GPS 실시간 속도계
- 총 거리 / 최고속도 / 평균속도
- 주행시간 / 휴식시간(3km/h 미만) 자동 분리
- OpenWeatherMap 날씨 연동
- ESP32 외부 온도 센서 연동

### 🚨 경보 시스템
- 과속 경보 (삐~ 2초 → 무음 3초 반복)
- 속도 확인 알림 3개 지점 설정

### 🎵 미디어
- 로컬 MP3 다중 재생목록 관리
- YouTube URL 자체 재생목록
- 본인만 청취 (팀원 전송 없음)

### 📋 주행 기록
- GPX 파일 생성
- 주행정보 TXT (날씨·온도·거리·속도·시간)
- 대화 녹음 (선택)
- Android: 폴더 지정 저장 / iOS: 다운로드

## GitHub Pages 배포 방법

1. 이 저장소를 Fork 또는 새 저장소에 파일 업로드
2. Settings → Pages → Source: **GitHub Actions** 선택
3. `main` 브랜치에 push하면 자동 배포
4. `https://{username}.github.io/{repo}/` 로 접속

## 사용 방법

### 방 개설
1. 앱 접속 → **통신** 탭
2. **방 개설** 버튼 → 6자리 코드 생성
3. 코드를 팀원들에게 공유

### 팀원 접속
1. 앱 접속 → **통신** 탭
2. 코드 입력 → **접속** 버튼

### 주행 시작
1. **주행** 탭 → **주행 시작** 버튼
2. GPS + GPX 기록 자동 시작
3. 설정에서 녹음 ON이면 대화 녹음도 시작

## ESP32 연동 (선택)

스마트폰 핫스팟에 ESP32 연결:
- 핫스팟 개설 → ESP32가 WiFi로 접속
- ESP32가 WebSocket 서버로 동작 (`ws://esp32.local:81`)
- 온도 데이터 수신 / GPS 속도 송신

## 기술 스택

- **Frontend**: Vanilla HTML/CSS/JS (Single File PWA)
- **P2P 통신**: PeerJS (WebRTC)
- **시그널링**: PeerJS Cloud (0.peerjs.com)
- **오디오**: Web Audio API
- **위치**: Geolocation API
- **저장**: localStorage + File System Access API
- **호스팅**: GitHub Pages
